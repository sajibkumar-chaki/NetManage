# NetManage Team Plan

## Project Objective

Develop a Python application that helps network technicians manage network device information and perform basic network checks and reporting.

## Team Roles

### Member 1 — Scrum Leader / Integration
- Project planning
- GitHub management
- Device management
- Integration
- Documentation

### Member 2 — Backend / Validation
- Search functionality
- IP validation
- Data handling

### Member 3 — Network Developer
- Connectivity checking
- Network diagnostics
- Error handling

### Member 4 — QA / DevOps
- Reporting
- CSV export
- Automated testing
- GitHub Actions
- CI/CD documentation

## Core Features

1. Add Network Device
2. View Devices
3. Search Device
4. Validate IP Address
5. Check Connectivity
6. Network Diagnostics
7. Generate Network Report
8. Export Device Data

## Future Backlog

- Web-based GUI
- Database integration
- Automatic device discovery
- User authentication
- SNMP monitoring
- Network topology visualisation
- Scheduled monitoring
- Cisco configuration automation

## Collaboration Process

1. Create an issue.
2. Assign the issue to a team member.
3. Create a feature branch.
4. Develop and test the feature.
5. Commit with a clear message.
6. Push the branch to GitHub.
7. Create a pull request.
8. Another member reviews the change.
9. Fix review comments if necessary.
10. Merge into `main`.

## Accountability

Each member should have:
- Assigned GitHub issues
- Feature-branch commits
- Pull requests
- Code-review participation
- Testing/documentation contributions
